# Self-Service Motion

A motion exploration for the Salesforce Self-Service Agent setup flow — the “magic” transition between the *Get Started* landing screen and the agent configuration screens.

This prototype is a static HTML / CSS / JS site. Open `index.html` directly, or view it live via GitHub Pages once enabled.

## Three motion explorations

The prototype lets a reviewer flip between three different takes on the transition:

1. **Sparkle** — a Lottie sparkle animation with the headline *“Crafting your help agent”*. Frame-accurate scrubbable timeline.
2. **Clarity** — a Lottie blur that resolves into focus while three lines of copy fade through. Timeline-driven so each beat is pause/scrub-able.
3. **Gesture** — a fullscreen WebGL gradient backdrop with the line *“Setting the stage for smarter service”* revealed word by word. Timeline-driven word reveal.

After the animation completes the prototype lands on a fully styled Agent Details screen matching the Figma frame (`Agent Config / 76`).

## Running locally

```bash
python3 -m http.server 5173
# then open http://localhost:5173
```

Any static-server will work; the prototype has no build step.

## Project layout

```
index.html       — single-page prototype shell (landing → creating → details)
styles.css       — all styles, structured by view; uses brand tokens from
                   .planning/brand/tokens.css
script.js        — view transitions, exploration runners, generic
                   timeline-driven playback engine, sparkle/grainient
                   lifecycle
grainient.js     — vanilla JS port of the React Grainient WebGL
                   gradient component (used in Gesture)
sparkle.json     — Lottie animation for the Sparkle exploration
fixed-blur.json  — Lottie animation for the Clarity exploration
assets/          — Figma-extracted PNG icons (side nav, header utilities)
.planning/       — brand-token outputs (tokens.json, tokens.css,
                   brand-sheet.html) generated by Salesforce's
                   extracting-brand skill
```

## Prototype controls

A dark “demo controls” strip is docked at the very top of the viewport
— it sits *outside* the design canvas so reviewers can tell at a glance
that it isn't part of the product UI.

- **Exploration pills**: switch between Sparkle / Clarity / Gesture before clicking Get Started.
- **Timeline scrubber**: appears while an exploration is playing — pause, restart, or drag to scrub frame-by-frame.
- **Restart demo**: appears once the animation finishes, returning you to the landing page so the next reviewer can play through.
